# 资料库文件夹与聚焦翻译设计

## 背景

资料库目前只有一个按置顶和最近阅读排序的文献列表，无法把同一门课程的多份 PDF 收纳在一起。阅读器的翻译面板会同时堆叠所有翻译卡片，记录较多时显得杂乱；同一高亮被重复点击时，React 可能因为选中 ID 没有变化而不再切换侧栏标签。

## 目标

- 支持创建、重命名和删除课程文件夹。
- 每份文献最多归入一个文件夹，并支持随时移动到其他文件夹或“未分类”。
- 删除文件夹时只解除归类，不删除 PDF、阅读进度、翻译、批注或词汇。
- 翻译面板一次只展示一条聚焦记录，正文仅显示原文和译文。
- 无论当前侧栏位于翻译、注释还是记录，点击任意蓝色高亮都会显示它对应的翻译。
- “加入词汇本”和“重新翻译”保留，但收进更多菜单。

## 非目标

- 首版不支持嵌套文件夹。
- 不支持同一文献同时归入多个文件夹；需要跨课程组织时可在后续版本增加标签。
- 文件夹是本机资料库的组织信息，不进入单文档批注包，不改变现有导出包版本。
- 不改变 DeepSeek 请求、翻译缓存键和 Token 消耗规则。

## 数据设计

新增 `LibraryFolder`：

- `id`：UUID。
- `name`：用户可见名称，去除首尾空白，长度限制为 1–60 个字符。
- `normalizedName`：经 Unicode 标准化、折叠空白并转小写后的唯一名称，用于防止重复。
- `createdAt` / `updatedAt`：ISO 时间。

`DocumentRecord` 新增可选 `folderId`。没有该字段的旧数据自然归入“未分类”，不需要重写 PDF Blob。

IndexedDB 升级到版本 3：

- 新增 `folders` 表，以 `id` 为主键，`normalizedName` 为唯一索引。
- `documents` 表增加 `folderId` 索引。
- 不对旧文献补默认文件夹，以免发生大 Blob 迁移。

文件夹删除使用单个 Dexie 写事务：先清除所属文献的 `folderId`，再删除文件夹记录。事务中不包含翻译、批注、词汇和 PDF 表的删除操作。

## 资料库交互

桌面端在文献列表左侧增加紧凑文件夹导航：

- 固定项：“全部文献”和“未分类”，均显示数量。
- 用户文件夹：按名称排序并显示文献数量。
- “新建文件夹”入口；每个用户文件夹提供重命名和删除操作。
- 移动端不固定左侧栏，改为文献列表上方的文件夹选择器。

文献行动作区增加文件夹按钮，打开“移入文件夹”菜单。菜单列出“未分类”和所有用户文件夹，当前位置显示选中状态。文献移动后立即刷新当前筛选和数量。

文献排序保持现有语义：在“全部”、“未分类”或任意文件夹中，置顶文献优先，其余按最近打开时间降序。

删除非空文件夹时显示确认对话框，明确提示“其中 N 份文献将移至未分类，文献和阅读记录不会删除”。

## 翻译聚焦交互

阅读器保存“当前侧栏标签”和“聚焦翻译请求”。聚焦请求包含 `markId` 和每次点击都会变化的 `requestId`，不再只用共享的 `translationId` 作为点击状态。

这样能同时处理两个边界情况：

- 同一缓存译文在不同页面或位置有多个高亮时，依然可以精确聚焦被点击的标记。
- 侧栏切换到注释或记录后，再次点击同一蓝色高亮也会生成新请求，强制切回翻译标签。

翻译标签的默认状态：

- 有翻译但没有显式聚焦时，展示最近更新的一条。
- 正文区一次只渲染一个翻译详情卡，卡片仅有“原文”和“译文”两块内容。
- 顶部提供折叠的“翻译记录 N”选择器。展开后以紧凑单行列表显示截断的原文，用户选择后关闭列表并切换聚焦卡。
- 卡片右上角的“更多”菜单包含“加入词汇本”和“重新翻译”。已加入词汇本时对应项显示已完成并禁用。
- 页码、源语言、目标语言、模型和时间不在翻译卡正文显示。

新翻译完成或命中缓存时，创建标记函数返回实际 `markId`，阅读器立即发出一次聚焦请求，因此用户不需要再点蓝色高亮才能看到译文。

## 组件边界

- 数据库模块负责文件夹唯一性、删除事务和版本迁移。
- `LibraryClient` 负责读取文件夹和文献数量，并把创建、重命名、删除和移动操作写入数据库。
- `LibraryScreen` 只负责当前文件夹筛选、对话框和菜单交互，不直接访问 Dexie。
- `PdfPage` 把具体 `markId` 传给阅读器，不决定侧栏状态。
- `ReaderClient` 控制侧栏标签与聚焦请求，解析 `markId` 对应的译文。
- `InspectorPanel` 负责单条详情、折叠历史列表和更多菜单的可见交互。

## 错误处理

- 空文件夹名、超长名称和重复名称均不写入数据库，在资料库页面显示简短中文提示。
- 移动文献前校验文件夹是否存在；目标不存在时不修改文献。
- 文件夹事务失败时保持原归类，并使用现有资料库消息区显示错误。
- 如果翻译标记引用的译文缺失，它不出现在历史选择器中；点击时侧栏保持翻译标签并显示“该翻译记录不存在”。

## 测试策略

单元测试：

- 文件夹名规范化和重复检查。
- IndexedDB 版本 2 升级到版本 3 后旧文献仍然存在且处于未分类。
- 删除非空文件夹后，文献、翻译、批注和词汇数量不变。
- 移动文献到存在文件夹或未分类。

组件测试：

- 创建、重命名和删除文件夹的对话框与计数变化。
- 文献移动后从当前筛选消失，在目标文件夹出现。
- 传入多条翻译时只渲染一个详情卡，历史列表默认折叠。
- 翻译卡正文仅显示原文和译文，更多菜单保留词汇本和重新翻译操作。
- 当前侧栏在注释或记录时，点击蓝色高亮会切回翻译并显示正确记录；重复点击同一标记仍有效。

浏览器回归：

- 创建课程文件夹，移入两份 PDF，刷新后归类保留。
- 删除该文件夹，两份 PDF 在未分类中可见且仍可打开。
- 在阅读器中从注释标签点击蓝色高亮，验证单条原文/译文卡、折叠历史和更多菜单。

## 验收标准

- 现有资料库无需重新导入，所有旧文献出现在“未分类”。
- 文件夹创建、重命名、文献移动和刷新恢复全部成功。
- 删除文件夹后只有文件夹记录和文献的 `folderId` 被清除。
- 翻译面板任意时刻最多显示一条详细翻译，正文不显示页码、语言、时间或操作按钮。
- 点击每一个蓝色高亮均显示对应译文，不因为之前点过相同标记而失效。
- 翻译缓存、词汇本、批注导出和 PDF 阅读行为保持现有语义。
