# 墨读 1.1.0

墨读的首个完整 Linux 桌面发行版。安装包已包含应用所需运行环境，不需要另外安装 Node.js 或 npm。

## 下载选择

- `Modu-1.1.0-x86_64.AppImage`：无需安装，添加可执行权限后直接运行。
- `Modu-1.1.0-x86_64.deb`：适用于 Debian、Ubuntu 及其衍生发行版，可注册应用菜单与 PDF 文件类型。

首次启动时可以选择将墨读设为 PDF 默认应用，也可以选择“以后再说”，之后在设置中完成。墨读不会在未确认时修改系统默认设置。

## 本版体验

- 连续阅读与双页图书模式，支持缩放、翻页动画和长文档按需渲染。
- 阅读器左侧精简为缩略图导航，桌面窗口移除系统默认菜单栏，把空间留给文档。
- DeepSeek 与 Google Cloud Translation 可在设置中切换，并使用本地缓存减少重复请求。
- 翻译标记、普通高亮、折叠注释与词汇卡片复习。
- 文件夹和文献支持拖动排序；文献也可以直接拖入文件夹分类，排列不会再随最近阅读时间改变。
- 启动后自动检查新版本，在设置中明确下载并重启安装，不会在阅读中静默更新。
- 删除前可导出阅读记录，删除文献后仍保留词汇。
- PDF、阅读进度与所有学习记录默认保存在本机。

发行页同时提供 `latest-linux.yml` 更新元数据。当前版本开始建立自动更新通道，后续 Linux 版本可以直接在应用设置中检查和安装。
