# 墨读 1.1.1

本版本集中修复阅读器缩略图、资料库操作和 Linux 桌面设置反馈，不改变 PDF 正文渲染与连续滚动策略。

## 修复与改进

- 恢复 PDF 页面的真实缩略图，按可见范围延迟绘制，并限制缩略图画布缓存数量。
- 缩略图使用独立单并发低优先级队列，正文页面始终优先渲染。
- 文献封面整体可直接拖动排序或拖入文件夹，移除左侧拖动按钮和提示文字。
- 移除资料库中的“未分类”入口；移出或删除文件夹后，文献仍保留在全部文献中。
- “更多”菜单支持点击页面其他位置关闭，翻译操作菜单同样适用。
- 修复设置 PDF 默认应用成功后仍显示“当前尚未设为默认”的问题。
- 精简“设置”“翻译偏好”和“PDF 默认应用”标题下方的说明文字。
- DeepSeek 与 Google API Key 改为持久保存；Linux 桌面端使用系统密钥环加密，密钥不进入阅读数据或导出包。
- 重启墨读时自动回到上次阅读的文献、模式、页码和缩放比例。
- 翻译单个词后自动加入词汇本，句子和段落不会自动混入。
- 从阅读器进入设置后，返回按钮会回到原文献阅读位置。

## 下载选择

- `Modu-1.1.1-x86_64.AppImage`：无需安装，添加可执行权限后直接运行。
- `Modu-1.1.1-x86_64.deb`：适用于 Debian、Ubuntu 及其衍生发行版。
